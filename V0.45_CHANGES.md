# v0.45

- Same `VitaAutoPluginHUD.skprx` kernel plugin.
- `R + Up`: toggle passive HUD.
- `Triangle + Up`: open/close separate Overclock overlay.
- CPU/GPU/BUS/XBAR selectable clock steps based on PSVshell-supported ranges.
- FPS BOOST toggles a max-performance clock preset; FPS counter remains real framebuffer FPS.
- APPLY applies current profile.
- SAVE applies and persists profile to `ur0:data/VitaAutoPlugin/overclock.bin`.
- RESET restores 333/111/166/111 MHz and disables boost.
- Saved profile is loaded/applied at plugin boot, but the Overclock overlay always starts CLOSED.
- Preserves v0.44 global SceDisplay HUD hook and MEM/GPU telemetry code.
