# Vita AutoPlugin v0.37

- Restored the standard taiHEN `TAI_CONTINUE` chain used by established Vita display-hook plugins.
- Background plugin is compiled as GNU C17 so `TAI_CONTINUE` keeps the legacy unspecified-argument function-pointer behavior expected by taiHEN.
- HUD starts visible after plugin load so LiveArea rendering can be verified immediately.
- R + D-pad Up still toggles the HUD and controller input is not modified/consumed.
- HUD remains transparent: only glyph pixels are written.
- MEM stays `N-A` until a verified memory metric is implemented.
