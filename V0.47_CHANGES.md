# v0.47 hardware safety fix

- Fixes the unsafe-shutdown path seen on real PS Vita when APPLY was pressed while Overclock was OFF.
- OFF is now true hands-off mode: no CPU/GPU/BUS/XBAR setters are called.
- SAVE only saves the selected profile; it no longer silently applies clocks.
- RESET returns menu values to stock defaults without forcing kernel clock setters.
- Saved values are loaded at boot, but are not auto-applied during boot, avoiding a boot-loop risk while APPLY is being hardware-validated.
- Existing global HUD/SceDisplay hook is unchanged.
- CPU 333 MHz is the normal/default displayed clock, not proof that overclock is active.
