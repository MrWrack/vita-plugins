# v0.41 - Global HUD architecture change

v0.39 proved the user-mode `.suprx` approach was not enough for the requested LiveArea HUD.

v0.41 therefore changes the global HUD to a **kernel plugin**:

- New output: `VitaAutoPluginHUD.skprx`
- Hooks the SceDisplay kernel framebuffer path used by established Vita HUD plugins.
- Starts visible after reboot so success is obvious immediately.
- R + D-pad Up toggles HUD visibility without consuming input.
- HUD is passive: no menu navigation.
- Shows FPS, CPU MHz, battery %, battery temperature.
- GPU and MEM intentionally show `N-A` until a verified kernel metric is implemented.
- The old `VitaAutoPluginBackground.suprx` is no longer the global-HUD path.

## config.txt for v0.41
Put this line under `*KERNEL`:

    ur0:tai/VitaAutoPluginHUD.skprx

Remove/comment the old VitaAutoPlugin background line under `*main` to avoid loading the obsolete user plugin:

    ur0:tai/VitaAutoPluginBackground.suprx

Reboot the Vita after replacing the plugin/config.

This source package is prepared for VitaSDK/GitHub Actions. It has not been hardware-tested by ChatGPT.
