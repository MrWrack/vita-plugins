# Vita AutoPlugin v0.20 – Functionality & Stability Fix

- Trophy Hunter, Trophy Unlocker, Auto Platinum and Backup Before Unlock are now persisted in settings.cfg.
- v0.19 9-value settings files remain backward compatible.
- Leaving Trophy menu no longer resets Trophy state.
- In-app L + SELECT Trophy Quick Menu opens only when Hunter + Unlocker are ON.
- In-app R + D-pad Up opens the normal Quick Menu.
- Circle closes an open Quick Menu without disabling Trophy settings.
- Save Working Config now reports success/failure.
- Create Backup Now reports success/failure and creates a latest backup plus numbered snapshots.
- Restore Last Working reports success/failure.
- Trophy writes remain intentionally blocked until title/trophy DB validation and verified backup/restore are complete.

## Background / in-game overlay
A normal VPK process cannot remain as a global overlay after the app is closed. A separate taiHEN plugin component is required for a real overlay inside other games/apps. v0.20 keeps the VPK-side state/hotkey behavior ready for that component, but does not falsely claim a global background overlay is implemented yet.
