# Vita AutoPlugin v0.32

- Fixes background-plugin link failure `undefined reference to main`.
- Builds the taiHEN user module with `-nostdlib`, so `module_start` / `module_stop` from `exports.yml` are used instead of the normal application CRT expecting `main()`.
- Background plugin build is now required to succeed in GitHub Actions.
- GitHub artifact now targets v0.32 and requires `VitaAutoPluginBackground.suprx`.
- Keeps the passive R + D-pad Up HUD toggle logic; the background module still does not claim global rendering until that renderer is implemented and tested on hardware.
