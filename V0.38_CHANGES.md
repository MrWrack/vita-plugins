# v0.38 LiveArea HUD visibility fix

- HUD remains visible immediately when the background plugin starts.
- R + D-pad Up only toggles visibility; it does not consume normal controls.
- HUD glyphs are rendered at 2x scale and moved to a safer top-right region for LiveArea.
- Drawing remains transparent: only glyph pixels are written.
- Keeps the established sceDisplaySetFrameBuf import hook used by Vita framebuffer plugins.
- MEM remains N-A until a verified global-memory metric is implemented.
