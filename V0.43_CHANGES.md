# v0.43 HUD telemetry/layout

- Keeps the proven v0.42 kernel SceDisplay hook.
- Moves the HUD to x=810, close to the right edge of the 960px display.
- Removes all `N-A` text. Unavailable optional rows are omitted.
- GPU: resolves the real ScePower ES4 GPU getter (same export/NID approach used by PSVshell) and shows live MHz.
- MEM: reads the current main address-space usage and shows used MB when available.
- FPS, CPU MHz, battery %, battery temperature and R+Up toggle remain.
- No fake memory temperature is added. TEMP remains the real battery/case temperature exposed by ScePower.
