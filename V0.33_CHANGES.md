# v0.33 Global HUD prototype

- Background `.suprx` now hooks `sceDisplaySetFrameBuf` (NID `0x7A410B64`) with taiHEN.
- Passive R + D-pad Up toggle; no controller input is consumed.
- Draws FPS, CPU, GPU, free user MEM, battery and battery temperature directly into the framebuffer.
- Install under `*main` for LiveArea/SceShell. To test in apps/games, also add the plugin under `*ALL`.
- This is hardware-test code: build success does not prove compatibility with every game/pixel format. Keep a config backup.
