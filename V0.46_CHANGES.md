# v0.46 - Overclock ON/OFF + CPU frequency choices

- Keeps the working global HUD/display hook unchanged.
- Triangle + Up opens/closes the Overclock overlay.
- Adds OVERCLOCK ON/OFF as the first selectable row.
- CPU choices are 333 / 444 / 500 MHz.
- GPU/BUS/XBAR remain independently selectable.
- FPS BOOST remains ON/OFF.
- APPLY applies the current profile.
- SAVE applies and stores the full profile, including ON/OFF.
- RESET restores defaults and switches Overclock OFF.
- Overclock menu always starts closed after reboot.
- R + Up remains the normal HUD toggle.
