# Vita AutoPlugin v0.30

- Normal Quick Menu is now a passive status HUD: no selection bar and no Up/Down/X handling.
- R + D-pad Up remains the only normal HUD show/hide chord.
- Normal controller input continues to the Vita AutoPlugin screen while the HUD is visible.
- TEMP now uses VitaSDK `scePowerGetBatteryTemp()` and converts the documented Celsius x100 value to Celsius.
- Invalid temperature readings display `TEMP N/A` rather than a fabricated value.
- MEM remains `N/A` until a verified memory metric is wired.
- The background plugin is still an alpha hotkey-state module; global rendering after the VPK closes is not claimed complete.
